## 03 项目概览 · 描述（968 / 1000）

```
Post a purse and a spec: fields to read off sources and rules. Competitors submit values; the contract checks each claim against the pages it fetched, pays the best.

For procurement and vendor due diligence: what is published, not what is claimed.

The model answers one question: what this page publishes. Each answer must occur verbatim as a whole token: 99 is not anchored by 1999, nor 50 by 50.00. A value the page does not publish verbatim is dropped.

Nothing else calls a model. Corroboration, rules, verdict, winner and payout are deterministic: a field counts only if >= min_sources sources publish that exact value; a rule over an unproven field is UNRESOLVED, not guessed.

Collection closes before scoring; all providers see one set.

Three exits, all moving real value: cancel, settle when nobody cleared the bar, settle when one did. The contract cannot keep the purse.

Run live on Bradbury with a real 1 GEN purse. 61 tests assert every fund movement.
```

## 回复 Steward（894 字符）

```
Fixed, using both options.

The evidence set is frozen before anyone is scored, and settlement re-scores everyone from scratch.

- collecting (now < collect_by): submit() refused, "Collection not final"
- submitting (collect_by <= now < submit_by): collect() refused, "Collection window closed"
- settling (now >= submit_by): settle() re-scores every entry from the frozen set before ranking

So no provider is scored on a half-collected set, the frozen set cannot change afterwards, and all are ranked on identical evidence.
```

## 修复说明（给 Steward 看的技术细节）

原实现里 `submit` 按**当下已采集的来源**打分，且分数永不重算。两个后果：

1. 先交的 provider 可能基于 2 个来源被打分，后交的基于 3 个 → 评分基准不同
2. 后续继续采集会让早交的分数变陈旧

**两条路都做了**：

```
collecting   now <  collect_by              collect() ✅  submit() ❌
submitting   collect_by <= now < submit_by  collect() ❌  submit() ✅
settling     submit_by <= now               settle() 重算所有条目后排名
```

- **证据在 `collect_by` 冻结**：没人能拿半成品证据集被打分
- **冻结后禁止再采集**：冻结的证据集无法被改动
- **`settle` 用 `_score()` 从头重算每一条**：即使上游有变，所有 provider 也在同一份最终证据上排名
