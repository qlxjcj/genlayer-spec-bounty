SpecBounty

Escrowed spec verification. Proven, or refunded.

What it is

A purse is posted together with a requirement spec: named fields to read off a set of authoritative sources, and deterministic rules over those fields. Competitors submit the published values. The contract checks every claim against the pages it fetched itself, scores it, and pays the best submission — or nobody at all, in which case the purse goes home.

Why the answers cannot be invented

The model is asked one narrow question: what does this page publish for each field? Every answer must then occur verbatim in the page as a whole token.

page saysclaimedanchored?
199999no — inside a longer number
50.0050no — inside a longer number
price: 50.50yes — the full stop is punctuation

A value the page does not literally publish is dropped and never becomes evidence. Nothing else in the contract calls a model: corroboration, rules, verdict, winner and payout are all deterministic code.

The payout rule

A field counts only if at least min_sources independent sources publish that exact value. Rules over unproven fields resolve to UNRESOLVED rather than being guessed.

outcomemeaning
PASSevery rule satisfied
PARTIALsome satisfied, none violated
FAILa rule violated
NOT_VERIFIABLEnothing resolvable — never paid for

Three exits, and every one of them moves real value:

  • cancel — requester, before any submission
  • settle — nobody cleared the bar → purse refunded
  • settle — someone cleared the bar → that provider paid

The contract cannot keep the purse.

Verified on chain

Run end to end on Bradbury with a real 1 GEN purse against two real Wikipedia sources. The submission the contract stored:

{"values":  {"lang": "en", "type": "standard"},
 "support": {"lang": 2, "type": 2},
 "proven":  {"lang": true, "type": true},
 "rules":   [{"field": "lang", "op": "==", "ref": "en", "result": "SATISFIED"}],
 "score": 2, "verdict": "PASS", "note": "score 2/2 PASS"}

support shows each field carried by two independent sources. The escrow, the corroboration, the rule engine and a real 1 GEN payout are all visible in the transactions on the Explorer link above. An earlier run closed its window with no submission and refunded the full purse (state: REFUNDED, note: "no submission").
